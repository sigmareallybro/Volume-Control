# Volume-Control
A program that changes the sound based on entered numbers. 
## How to Use?
Open the program and enter a number, for example:
50
or
50%
(it doesn't matter; both options work)
Your sound will then change.
Commands:
help
clear
clean.
## Why Antivirus Detect it like Malware?
To ensure the program runs correctly, I use a DLL file; this allows the sound to be modified without errors or restrictions from Windows.
If the antivirus flags the program, add my program to the exclusion list.
